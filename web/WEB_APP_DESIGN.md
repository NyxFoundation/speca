
SPECA web client の設計
========================
## 1. 動機

SPECA の入力は原状githubActionのみである。
出力はJSON＋Markdownであるが、査読者がこれを直接読むのは困難である。
以下の課題がある:

- 査読者が PARTIAL JSON を手動で確認する必要がある
- 3 フェーズ監査の推論過程が JSON に埋もれている
- パイプラインのデモが困難（CLI 依存）
- RQ1/RQ2 の結果が静的で動的フィルタリング不可
- Mermaid `.mmd` がレンダリングされていない
